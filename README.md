# Fundraising Campaign Prediction – Data Mining II

## Project Overview

This project focuses on developing a predictive model to identify individuals who are most likely to donate to a fundraising campaign.

Using historical campaign data, the objective was to predict donation behaviour and help a nonprofit organization improve its outreach strategy by targeting individuals with a higher likelihood of responding positively.

## Objectives

- Explore and preprocess the dataset through Exploratory Data Analysis (EDA).
- Identify relevant patterns and relationships within the data.
- Develop binary classification models to predict donation behaviour.
- Compare different models and evaluate their generalization performance.
- Optimize model performance through techniques such as hyperparameter tuning and feature selection.
- Analyse feature importance and model predictions to extract actionable insights.

## Methodology

**1. Data Exploration and Preprocessing**
- Data cleaning and preparation.
- Exploratory Data Analysis.
- Feature analysis and transformations.

**2. Predictive Modelling**
- Development of binary classification models.
- Comparison of candidate models using a consistent evaluation strategy.
- Hyperparameter tuning and model optimization.
- Model evaluation based on the F1-score.

**3. Model Interpretation and Results**
- Comparison of model performance.
- Analysis of feature importance.
- Examination of incorrect predictions and model behaviour.
- Submission of predictions to a Kaggle competition.

## Technologies

- Python
- Jupyter Notebook
- Machine Learning – Supervised Learning
- Binary Classification
- Kaggle

## Project Information

Academic group project developed as part of the Data Mining II course at NOVA IMS.

The project involved the development and evaluation of predictive models using historical fundraising campaign data.
